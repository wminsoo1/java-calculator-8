# java-calculator-precourse

## 기능 목록

1. **입력 안내 문구 출력**
    - "덧셈할 문자열을 입력해 주세요." 출력

2. **문자열 입력 받기**
    - `Console.readLine()`을 사용하여 사용자로부터 문자열 입력 받기

3. **입력값 검증**
    - 빈 문자열("") 입력 시 0 반환
    - 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException` 발생

4. **구분자 처리**
    - 기본 구분자: 쉼표(,) 및 콜론(:)
    - 커스텀 구분자: `"//"`와 `"\n"` 사이에 정의된 문자 사용
        - 예: `"//;\n1;2;3"` → 구분자 `;`

5. **문자열에서 숫자 추출**
    - 구분자를 기준으로 문자열 분리
    - 각 숫자를 `int`로 변환 후 합산

6. **결과 출력**
    - "결과 : 답" 형식으로 결과 출력
